# Simple Calculator 🧮

A beginner-friendly **command-line calculator** written in Python.  
This project is designed to help new programmers practice core Python concepts such as functions, loops, conditionals, and input validation.

---

## ✨ Features

- ➕ **Addition**
- ➖ **Subtraction**
- ✖️ **Multiplication**
- ➗ **Division** (with division-by-zero protection)
- 🔁 **Repeat mode** — keep calculating without restarting the program
- ✅ **Input validation** — handles invalid numbers and invalid menu choices gracefully
- 📖 **Well-commented code** — easy to read and understand

---

## 🚀 How to Run

### Requirements
- Python 3.x installed on your machine  
  → Download from [python.org](https://www.python.org/downloads/)

### Steps

1. **Clone or download** this repository to your computer.
2. Open a **terminal** (Command Prompt, PowerShell, or any terminal).
3. Navigate to the folder containing `calculator.py`:
   ```bash
   cd path/to/project-folder
   ```
4. Run the program:
   ```bash
   python calculator.py
   ```
